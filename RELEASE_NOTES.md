# Cloudflare Turnstile v1.0.2

First GitHub release of the user-tested Panel 2.0 integration.

**Highlights**
- Cloudflare Siteverify-backed protection for login and password recovery.
- Administrator-managed Site Key, Secret Key and enabled toggle.
- Turnstile setting defaults to OFF.
- Fresh installations are **disabled** when installed without `--enable`.

**Install**
Download `cloudflare-turnstile-v1.0.2-source.zip` and follow README.md.

**Compatibility**
Tested by the project user on their Pterodactyl Panel 2.0 environment. This package has not been independently tested against other Panel revisions.
